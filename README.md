# CodeAlpha Basic Chatbot

A simple rule-based chatbot developed using Python as part of my CodeAlpha Python Programming Internship.

## Features

- Responds to basic user messages
- Supports greetings and simple conversations
- Uses predefined responses
- Continues chatting until the user types "bye"

## Technologies Used

- Python
- Functions
- if-elif statements
- while loop
- Input and output

## Supported Messages

- hello
- how are you
- thanks
- bye

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code or a terminal.
4. Run:

```bash
python chatbot.py
